# DRCC Contact Centre (prototype)

A clickable prototype of the in-house contact centre and case system for the Debt Review Cancellation Centre (DRCC, NCR reg. NCRDC3239).

It includes a speed-to-lead dialer, a case pipeline from enquiry to clearance at the four credit bureaux, document and bureau tracking, and a WhatsApp, email and webchat inbox in English and Afrikaans.

All names, phone numbers and cases are **sample data**. The page is a single static file, `index.html`, and needs no build step.

See [PLAN.md](PLAN.md) for the build plan.
